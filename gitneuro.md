
#La différence entre Git et GitHub

##Git (L'outil)
Qu'est-ce que c'est ? Git est un système de contrôle de version décentralisé. C'est un logiciel que vous installez directement sur votre ordinateur.

Son rôle : Il enregistre l'historique de toutes les modifications apportées à votre code source au fil du temps. Il vous permet de revenir en arrière, de comparer des versions, de travailler sur plusieurs fonctionnalités en même temps (via les branches) et de fusionner votre travail.

Fonctionnement : Il fonctionne entièrement en local, sur votre machine, sans nécessiter de connexion Internet.

##GitHub (La plateforme)
Qu'est-ce que c'est ? GitHub est un service web d'hébergement de code basé sur le cloud.

Son rôle : Il sert de "garage" ou de vitrine en ligne pour stocker les projets créés avec Git (vos dépôts ou repositories).

Fonctionnement : Il permet de centraliser le travail pour faciliter la collaboration en équipe (partage de code, revue de code, gestion des tâches avec les issues, et validation des modifications via les pull requests). D'autres alternatives similaires existent, comme GitLab ou Bitbucket.

###La différence fondamentale entre Git et GitHub réside dans le fait que l'un est un outil logiciel de suivi, tandis que l'autre est une plateforme d'hébergement en ligne.
